Understanding the Metrics — Class Imbalance Context

Authorization vulnerabilities are extremely rare in production code: only 81 confirmed vulns in 15,597 endpoints (0.52% positive rate).

At this imbalance level, even a hypothetical detector with 1% FPR would produce ~156 false alarms vs. 81 true positives → max achievable precision ≈ 34%. Our rule baseline's precision of 4.0% is consistent with this fundamental constraint.

The correct framing is triage efficiency: how much manual review is needed to find each real vulnerability.

Research Contributions & Key Findings

C1. Novel graph representation for authorization analysis. The Program Flow Graph (PFG) encodes endpoint-to-data-access-to-auth relationships, enabling automated detection where pattern-matching tools (Semgrep, CodeQL) find zero results. PFG-based detection is the only approach that identifies auth vulnerabilities in our corpus.

C2. Largest authorization vulnerability benchmark. A corpus of 75 real-world applications (15,597 endpoints) with ground-truth labels from 81 confirmed CVEs spanning 5 vulnerability subtypes (MISSING_AUTH, MISSING_ROLE, IDOR, TENANT_ISOLATION, OBJECT_PERMISSION).

C3. Effective hybrid architecture. GNN+Rules validation reduces false positives by 97% (3,983→116 FP) while maintaining 67% recall. The two-stage design combines GNN's pattern recognition (high recall) with rule-based verification (high precision).

C4. Quantified synthetic-to-real transfer gap. GNN trained on synthetic data achieves macro-F1=0.72 on synthetic test set but F1=0.002 on real code. This 360× performance drop demonstrates that authorization vulnerability patterns in real-world code differ substantially from synthesized examples — motivating future work on better synthetic generation or few-shot adaptation.

C5. Rule refinement delivers consistent gains. Iterative rule improvement (v1→v4) reduced FPs by 26% (261→194) without sacrificing recall, through techniques including admin-path exclusion, parent-class auth resolution, and DRF action-based detection. This confirms that domain knowledge encoding remains highly effective for this problem class.

Limitation: Incomplete ground truth. Only CVE-reported vulnerabilities are labeled; many flagged endpoints may be true unlabeled vulnerabilities. Reported FP counts are therefore upper bounds, and actual precision is likely higher than measured.
