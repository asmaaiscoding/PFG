#### 3.2.2 Taxonomy of Targeted Access Control Vulnerabilities
**Prompt:** *"Write a formal taxonomy section covering three access control vulnerability classes: (1) Missing Authentication — endpoints reachable without any identity verification; (2) Missing Authorization — endpoints that verify identity but not permission level; (3) Insecure Direct Object Reference (IDOR) — endpoints that expose internal object identifiers without ownership verification. For each class, provide: a formal definition, a minimal code example, the CWE identifier (CWE-306, CWE-862, CWE-639), and the OWASP Top-10 2021 mapping. Distinguish them clearly from each other."*

**Mermaid diagram here:** A taxonomy tree.

    MA --> MA2[Bypassed login gate]
    MZ --> MZ1[Role not verified]
    MZ --> MZ2[Privilege escalation]

    IDOR --> IDOR2[Predictable file path]

**Prompt:** *"Describe the high-level architecture of a four-stage pipeline: (1) Source Code Ingestion and Parsing, (2) Code Property Graph Construction and Privilege Flow Extraction, (3) GNN-Based Vulnerability Classification, (4) Explainable Report Generation. Justify each stage's role. Use precise software engineering vocabulary."*

### 3.4 Graph-Based Code Representation

#### 3.4.1 Code Property Graph Construction
**Prompt:** *"Describe in detail the construction of a Code Property Graph (CPG) by composing three sub-graphs: the Abstract Syntax Tree (AST), the Control Flow Graph (CFG), and the Program Dependence Graph (PDG). Explain how these three graphs are unified into a single heterogeneous graph. Use a concrete minimal code example (a Python Flask endpoint) and show how each node type and edge type is derived from it."*

**Mermaid diagram:** Show how AST, CFG, PDG merge into CPG for a simple Flask route.

#### 3.4.2 Privilege Flow Modeling
**Prompt:** *"Define what constitutes a privilege flow in the context of web applications: the sequence of nodes in the CPG from an HTTP entry point, through any authentication/authorization check nodes, to a data access or object retrieval node. Describe the algorithm used to extract privilege flows as subgraphs. Explain how flows with missing checks are identified structurally. Provide a pseudocode algorithm."*

#### 3.4.3 Node and Edge Feature Engineering
**Prompt:** *"Describe the feature vectors assigned to nodes and edges in the privilege flow subgraph. For nodes: include node type (one-hot), token embedding (using a pre-trained CodeBERT or simple vocabulary), line number, and security-relevant keywords (e.g., @login_required, hasRole, findById). For edges: include edge type (AST/CFG/PDG) and direction. Justify each feature's relevance to access control detection."*

---

### 3.5 GNN-Based Vulnerability Detection

#### 3.5.1 Graph Neural Network Architecture
**Prompt:** *"Describe the chosen GNN architecture for graph-level classification of privilege flow subgraphs. Compare Graph Convolutional Network (GCN), Graph Attention Network (GAT), and GraphSAGE, and justify the final selection. Describe the number of layers, hidden dimensions, pooling strategy (global mean/max pooling), and the final classification head. Provide the mathematical formulation of the message-passing step."*

#### 3.5.2 Multi-Class Classification Strategy
**Prompt:** *"Explain how the three vulnerability classes (Missing Authentication, Missing Authorization, IDOR) and the safe class are handled as a 4-class graph classification problem. Discuss the class imbalance problem and the mitigation strategy used (oversampling, weighted loss, or data augmentation). Present the loss function."*

#### 3.5.3 Explainability via Subgraph Attribution
**Prompt:** *"Describe how GNNExplainer (or an equivalent method such as SubgraphX or PGExplainer) is applied post-classification to identify the critical subgraph responsible for the vulnerability prediction. Explain how the attributed subgraph is mapped back to source code lines and how this forms the basis of the remediation report."*

**Mermaid diagram:**

```mermaid
flowchart LR
    A[Full CPG Subgraph] --> B[GNN Forward Pass]
    B --> C[Predicted Class:\nMissing Auth]
    C --> D[GNNExplainer\nMask Learning]
    D --> E[Critical Nodes\nattention_required=False\nno @login_required]

```
